# BillFlow Product Blueprint

## Positioning
BillFlow is a household bill operating system for planning, paying, and protecting recurring financial obligations.

## User Flow
1. Discover billers.
2. Organize financial obligations.
3. Schedule payments.
4. Monitor account health and protection signals.
